== PLUGINS ==

ponytail (v4.13.0)
  Mode "developpeur paresseux" : la solution la plus courte qui marche.
  Niveaux : lite (construit ce qui est demande, signale l'alternative), full (defaut), ultra.
  Commandes : /ponytail lite|full|ultra, "stop ponytail" pour couper.
  Autres : ponytail-audit, ponytail-debt, ponytail-gain, ponytail-help, ponytail-review.
  A faire : badge de barre d'etat, ajouter a ~/.claude/settings.json :
    "statusLine": { "type": "command", "command": "bash \"/Users/pat/.claude/ponytail-statusline.sh\"" }

graphify
  Transforme le code et les docs en graphe de connaissances (graphify-out/).
  Commandes : graphify query "<question>", graphify path "<A>" "<B>", graphify explain "<concept>".
  Le hook git post-commit reconstruit le graphe en tache de fond (incremental).
  Ne pas lancer "graphify update ." a la main (~3 min). Sur un clone neuf : le lancer une fois.
  graphify-out/ n'est pas versionne.

Autres plugins actifs : ecc (everything-claude-code), code-simplifier, frontend-design,
design, finance, productivity, pdf-viewer.

== AUTRES OPTIMISATIONS ==

RTK (Rust Token Killer)
  Proxy CLI qui filtre les sorties de commandes (60-90 % de tokens en moins).
  Hook automatique : git status -> rtk git status.
  rtk gain (analytique), rtk discover (occasions manquees), rtk proxy <cmd> (sortie brute).

CLAUDE.md
  Global (~/.claude/CLAUDE.md) : francais, concis, stack Laravel/Livewire/Alpine/Tailwind, autonomie.
  Projet (CLAUDE.md a la racine) : prevaut sur le global. Charte graphique dans Claude_design.md.
  Design generique : ~/.claude/CLAUDE.Design.md.
