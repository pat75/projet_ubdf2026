Pour qui ?

Vous cherchez des créatifs sans publier vous-même de portfolio : directeur artistique, éditeur, agence, recruteur ou client. Le compte visiteur est fait pour vous.

Il est gratuit, sans formule ni durée limite. Une adresse mail et un mot de passe suffisent.

Ouvrir son compte

  1. Sur le portail, cliquez sur le cœur d’un portfolio : Dustfolio vous propose de créer votre compte.
  2. Indiquez votre adresse mail et un mot de passe : vous êtes connecté dans la foulée.
  3. Les portfolios gardés auparavant dans votre navigateur rejoignent votre compte.
  4. Un mail de confirmation part aussitôt ; vous pouvez le redemander depuis le tableau de bord.

Votre tableau de bord

Dès la connexion, vous retrouvez vos memoBooks, vos derniers messages avec les créatifs et vos dernières visites, pour remettre la main sur un portfolio consulté la veille.

Le memoBook, votre sélection

  • Garder : le cœur d’un portfolio l’ajoute à votre memoBook ; un nouveau clic l’en retire.
  • Chercher dans votre sélection par nom.
  • Partager : le partage public produit un lien en lecture seule, à envoyer à un client ou à votre équipe.
  • Exporter en PDF : la sélection mise en page, avec si vous le souhaitez un QR code qui ouvre chaque portfolio sur téléphone.

Le memoBook est lié à votre compte : il vous suit d’un appareil à l’autre.

Écrire aux créatifs

  • Contactez un créatif depuis son portfolio ou depuis votre memoBook.
  • Mes messages regroupe les échanges par créatif et signale les messages non lus.
  • Vous répondez dans la conversation ; une correction IA peut relire votre texte avant l’envoi.

Votre compte

  • Prénom et nom : ils signent vos messages et votre memoBook partagé.
  • Adresse mail (confirmée par un lien) et mot de passe se modifient à tout moment.
  • Newsletter des sélections : abonnement ou désabonnement en un clic.
  • Suppression du compte quand vous le voulez : memoBook, visites et partage public sont effacés. Les messages déjà envoyés restent chez leurs destinataires.

Questions fréquentes

Le compte visiteur deviendra-t-il payant ?

Non. Les formules payantes concernent uniquement les créatifs qui publient un portfolio.

Je publie déjà un portfolio : ai-je besoin d’un compte visiteur ?

Non. Votre espace créatif comprend déjà le memoBook et la messagerie.
